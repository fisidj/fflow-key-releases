# FFlow Key — Descargas oficiales

**FFlow Key** — Arma sets armónicamente perfectos en minutos.

Este repositorio aloja los instaladores oficiales de FFlow Key. El código fuente vive en un repositorio privado; aquí solo se publican los binarios firmados y el manifiesto del auto-updater.

## Descargar

Ve a [**Releases**](https://github.com/fisidj/fflow-key-releases/releases/latest) y elige el instalador para tu sistema:

| Sistema | Archivo |
|---|---|
| Windows 10/11 | `.msi` o `-setup.exe` (NSIS) |
| macOS (Intel y Apple Silicon) | `.dmg` |
| Linux | `.AppImage` o `.deb` |

## macOS — primera apertura

Si macOS muestra "no se puede abrir": haz **click derecho** (Ctrl+click) sobre el icono y elige **Abrir**. Solo es necesario la primera vez.

## Actualizaciones

La app se actualiza sola: comprueba este repositorio al arrancar (manifiesto `latest.json` firmado con la clave del updater de Tauri).
